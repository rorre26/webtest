# Gallery Walk

Прототип 2D веб-приложения "Gallery Walk" с управлением персонажем, интерактивными картинами и просмотром серий в модальном окне.

## Запуск

### Вариант 1 (Linux/macOS)

```bash
./start.sh
```

Откройте [http://localhost:8000](http://localhost:8000).

Если нужен другой порт, задайте переменную окружения:

```bash
PORT=3000 ./start.sh
```

### Вариант 2 (Windows)

```bat
start.bat
```

Если нужен другой порт:

```bat
set PORT=3000
start.bat
```

### Вариант 3 (вручную)

```bash
python3 -m http.server 8000
```

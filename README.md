# Онлайн запись поставок на склад

Небольшое веб-приложение для планирования поставок на склад: сотрудник выбирает дату и время, запись появляется в общем графике, а архив можно выгрузить в Excel (CSV).

## Возможности
- Создание записи поставки с сотрудником, поставщиком, временем и контактами.
- Общий интерактивный график поставок с группировкой по датам.
- Экспорт архива в CSV (открывается в Excel).
- Локальное хранение данных (localStorage) для демонстрации.

## Запуск
Откройте `index.html` в браузере или запустите простой сервер:

```bash
python -m http.server 8000
```

После этого приложение будет доступно по адресу `http://localhost:8000`.
